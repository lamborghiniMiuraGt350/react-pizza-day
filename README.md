# 🍕 React Pizza Day

Пет-проєкт інтернет-магазину піци, реалізований на React з використанням TypeScript та Redux Toolkit. Проєкт імітує реальний e-commerce флоу: від каталогу товарів до оформлення замовлення.

**🔗 Демо:** [посилання на GitHub Pages]
**📦 Репозиторій:** github.com/lamborghiniMiuraGt350/react-pizza-day

## Функціонал

- 📋 **Каталог товарів** — список піц із зображеннями, цінами та варіантами (розмір, тип тіста)
- 🔍 **Фільтрація та сортування** — фільтр за категоріями, сортування за ціною/популярністю/алфавітом
- 🛒 **Кошик** — додавання/видалення товарів, зміна кількості, підрахунок підсумкової суми
- 💾 **Збереження стану кошика** між сесіями
